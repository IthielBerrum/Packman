# Actividad 3 - Juego de Pacman

## Descripción

Este proyecto corresponde a la Actividad 3 de Herramientas Computacionales.

Se utilizó como base el juego Pacman de la colección Free Python Games, desarrollada por Grant Jenks.

La actividad consistió en modificar diferentes características del videojuego y utilizar GitHub para integrar los cambios mediante un flujo de trabajo colaborativo.

## Modificaciones realizadas

Se realizaron las siguientes modificaciones:

1. Se modificó el diseño del tablero del juego.
2. Se creó una nueva distribución de paredes y caminos.
3. Se incrementó la velocidad de movimiento de los fantasmas.
4. Se mantuvo el funcionamiento general del juego original de Pacman.

Estas modificaciones aumentan la dificultad del juego y permiten trabajar con diferentes configuraciones del tablero.

## Controles

- Flecha arriba: mover a Pacman hacia arriba.
- Flecha abajo: mover a Pacman hacia abajo.
- Flecha izquierda: mover a Pacman hacia la izquierda.
- Flecha derecha: mover a Pacman hacia la derecha.
